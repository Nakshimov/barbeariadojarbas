# Barbearia Esboço 2 — Barbearia do Jarbas

Abra `index.html` em um navegador. As fotos ilustrativas são imagens reais de banco do Pexels, carregadas pela internet, com créditos linkados nas próprias imagens.

## Antes de publicar

- Troque os textos e os preços demonstrativos por informações confirmadas.
- Substitua as fotos de banco por imagens reais e autorizadas da barbearia.
- Preencha endereço, telefone/WhatsApp e horário nos campos marcados.
- Para ativar o agendamento, edite `const whatsappNumber = "";` no fim de `index.html` e informe o número real com DDI e DDD, somente dígitos.
- Os três depoimentos são fictícios; troque-os por avaliações reais autorizadas ou remova a seção.

Este é um modelo para personalização, não uma declaração de que seja o site oficial da barbearia.
